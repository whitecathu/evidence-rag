# 简历项目描述

### Evidence RAG｜可溯源技术文档问答系统｜独立开源项目

**技术栈：** Python、FastAPI、Vue 3、TypeScript、Qdrant、SQLite、BM25、Docker。

- 实现 Markdown/TXT/PDF 文档导入、标题感知分块与索引管理，保留页码和段落信息，支持内容去重、失败重试及文档删除后的索引清理。
- 构建向量检索与 BM25 的 RRF 融合链路，提供检索调试和可配置重排接口，支持对比不同策略下的召回结果。
- 使用 SSE 输出回答与来源证据，在前端提供引用展开和原文定位，校验引用编号并区分演示模式与真实模型调用。
- 建立 60 条证据标注问题集，覆盖单文档、跨文档及无答案场景，提供 Recall@5、MRR@5 与延迟的可复现评测脚本及 CI 检查。

**开源地址：** https://github.com/whitecathu/evidence-rag

以上是工程实现描述。投递时应确认自己能解释代码和取舍；真实模型质量指标、业务用户数、Star 数暂未作为成果填写。
