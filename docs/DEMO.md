# 三分钟演示

1. 按 README 启动后，运行 `uv run python scripts/seed.py`，刷新页面，确认 10 个文档 ready。
2. 提问“如何处理 API 请求失败后的重试？”，展示 SSE 摘录、引用编号、原文定位。强调页面顶部的 DEMO 标记。
3. 使用“只看检索”，比较 vector 和 hybrid 排序，不宣称哪个策略必然更好。
4. 上传同一文件，确认没有产生第二份重复文档；上传空 TXT，查看失败提示并说明重试机制。
5. 新建空知识库，提同样的问题，验证“没有足够证据”。删除测试文档后确认检索结果不再包含该文档。
6. 展示 `evals/questions.json` 与检索报告，说明真实模型效果等待单独 live 评测。
