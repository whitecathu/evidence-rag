# Atlas 示例工程手册：API 请求与重试

> 本文为本项目原创的虚构技术规范，用于演示，不是通用生产建议。

## API 超时

Atlas API 客户端连接超时为 3 秒，读取超时为 20 秒。超过读取超时返回 timeout 错误。

## API 重试

API 请求失败后，仅对 429、502、503 和网络超时重试。最多重试 3 次，等待 1、2、4 秒并增加随机抖动。

## API 幂等

支付创建请求必须携带 Idempotency-Key，服务端保存该键 24 小时。同键不同请求体返回 409。

## API 错误

API 错误响应包含 code、message、request_id 三个字段。日志按 request_id 关联上下游调用。
