# Atlas 示例工程手册：密钥与权限

> 本文为本项目原创的虚构技术规范，用于演示，不是通用生产建议。

## 密钥保存

模型 API 密钥仅保存在服务端环境变量，不写入仓库、浏览器存储或任务日志。

## 密钥脱敏

日志过滤 Authorization、api_key、access_token 字段；异常记录只保留错误类型和 request_id。

## 权限隔离

知识库检索必须携带 workspace_id 过滤条件，删除和读取接口也要验证资源所属空间。

## 路径校验

文件工具先规范化路径并解析链接，再验证最终路径位于工作区根目录内，禁止访问 .git 与 .env。
